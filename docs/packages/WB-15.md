## 用户的话（2026-10-23）
「目前 html 我只能看到美术、音乐相关的菜单，但是完全没有玩法设计相关的文档菜单。」用户决定玩法设计文档也放美术仓库（DSN-11 搬进来），在同一个 HTML 里看。

## 背景（已核对）
- 工作台左栏 6 个入口（总览、资源库、场景与界面、确认、地图概念、声音），没有任何文档入口；连美术仓库自己的 `docs/design/` 五份文档（美术规范、美术流程、界面风格、声音、工作台设计）都只能在编辑器里看。
- 双击打开（file://）时浏览器不允许用脚本读本地 `.md` 文件，所以要像 `data/bundle.js` 一样，先由工具把文档打包成一个数据脚本。
- 不能引入 npm 依赖或外部网络资源，Markdown 要用自己写的小渲染器。

## 目标
左栏多一个「文档」入口：左边是按分组排的文档目录（可搜索），右边是排好版的正文；文档里的图片、表格、代码块、文档之间的链接都能正常显示和跳转。以后往 `docs/design/` 里加文档，跑一次构建就出现在菜单里。

## 要读的（只读这些）
- `workbench/js/app/nav.js`、`main.js`、`views/home.js`
- `docs/design/*.md`（看看用到了哪些 Markdown 写法：标题、表格、代码块、图片、相对链接）
- `tools/screens.mjs`（照它的写法做 build / check）

## 要做的
1. **新建 `tools/docs.mjs`**：
   - `node tools/docs.mjs build`：扫描 `docs/design/**/*.md`，写 `workbench/data/docs.js`（`window.PB_DOCS = { docs: [{ path, group, title, text }] }`）；内容没变时不改文件。
   - 分组按目录：`docs/design/*.md` →「美术与界面」；`docs/design/gameplay/**` →「玩法设计」（DSN-11 会建这个目录；没有时这一组不显示）；以后新目录按目录名自动成组，组名写在 `tools/docs.mjs` 里的一张小表。
   - 标题取文件第一个 `# ` 标题。
   - `node tools/docs.mjs check`：`docs.js` 和文档一致（没重新构建就报错）；文档里的相对链接指向的文件存在（指向仓库外的路径只警告不报错）。
2. **新建 `workbench/js/app/markdown.js`**：只用原生 JS 的小渲染器，支持标题、段落、粗体 / 斜体、行内代码、代码块（含 ```jsonc 这类语言标记，只做等宽显示）、有序 / 无序列表（至少两层）、表格、引用、链接、图片、分隔线；所有文本先转义，不执行文档里的任何 HTML 或脚本。
3. **新建「文档」页**（`workbench/js/app/views/docs.js`，左栏第 7 个入口「文档」，地址 `#docs/<文档路径>`，例如 `#docs/design/art-direction.md`，可以带 `#小节`）：
   - 左边目录按分组列出，带搜索（标题和正文都搜，显示命中片段）；右边是正文和本文小节目录。
   - 文档之间的相对链接在工作台里跳转；指向 `art/`、`workbench/` 等仓库内文件的链接用普通链接打开；指向仓库外（如游戏仓库）的写法原样显示文字。
   - 图片按文档所在目录解析（例如 `ui-style/lobby/overview.png` → `../docs/design/ui-style/lobby/overview.png`），像素图用 `image-rendering: pixelated`，点开看大图。
4. 总览「快捷入口」加「文档」；总览加一句「设计文档 N 份」。
5. `workbench/index.html` 加载 `data/docs.js`、`markdown.js`、`views/docs.js`；`README.md` 的工作台说明加一句「文档」入口和 `node tools/docs.mjs build`。

## 验收
- `tests/docs.test.mjs`：渲染器对每种写法各有一个用例（含转义：文档里写 `<script>` 只显示成文字）；build 重复执行不改文件；check 能发现「没重新构建」和「断链」。
- smoke：左栏有「文档」；五份 `docs/design/*.md` 都能打开，`ui-style.md` 的图片能显示，文档间链接能跳转，搜索「调色板」能找到美术规范。
- 打开文档页最长主线程阻塞 < 200ms，停着不动 CPU < 5%。
- 截图（放 `../pushbox-evidence/WB-15/`）：文档页目录 + 正文、带表格的文档、带图片的文档、搜索结果。
- 验收整套通过（含 `node tools/docs.mjs check`）。
