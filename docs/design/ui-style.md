## 3 固定界面：默认 S1 晶石琉璃 · 素版

> **2026-10-17 用户改了决定**：固定界面（大厅以外的游戏界面）要换成**通用风格**。
> - **原因**：现在的 S1 晶石琉璃偏向某一种固定风格，不通用。
> - **新风格**：不属于任何一张地图，放在暗的地图（石牢、地府）和亮的地图（海女村、云端）上都好看、好读；休闲、清爽。
> - **怎么定**：先由外包出几个风格提案（UI-09），用户选一个；再按选定的风格做出一整套（UI-10），包括配送 v2 的界面。
> - **另加一套通用风格的大厅**。原来的大厅按章节换皮肤**保留**；通用大厅用在还没有自己皮肤的地图上（现在是地府、海女村）。
> - **已选定（2026-10-17）**：**G2 深蓝圆角**（UI-09），用户原话"G2.png 就是我想要的风格，直接按照这个生成吧"。
> - **在选定之前**：下面的 S1 素版只算过渡，用户不用确认这些固定界面；设置里的「界面风格」（四套切换）和 UI-07 暂停，等新风格定了再决定要不要。

除大厅外的界面不随地图换，默认用 S1 的素版（不带漂浮碎晶和晶簇）。玩家可在 设置 → 界面风格 里换成另外三套。**目前只画了 S1 素版；另外三套的固定界面组件还没画，是后续工作（UI-07）。** 设计负责人 2026-10-16 定：四套固定界面画齐、用户确认之前，设置里不显示「界面风格」这一项，免得玩家选到没画完的风格。

要点：
- 暂停菜单常用项旁标快捷键（Esc / H / R）；配送暂停用同一套画法。
- 提示由主角气泡说出，挂「提示 n/3」；底栏是层数 + 演示 / 回到正确位置。
- 对话三种样式：NPC 说话泡（青）、主角心里话（思考泡）、系统提示条（紫）。
- 选关预览用真实关卡截图 + 一句话发现；过关画面用门的打开帧（`mech.door` 第 4 帧）。
- 商店买不起的价格标红、卖完整行变暗；结算右上评级徽章、账单式明细、合计放大；失败标题用粉色。
- HUD：沙袋为 0 时用压暗的沙袋图标 + 灰色「×0」。
